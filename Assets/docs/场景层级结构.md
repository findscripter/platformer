## 主循环脚本挂载

`Managers` 下每个主循环组件对应独立对象，互不混挂：

| 对象 | 脚本 | 说明 |
| --- | --- | --- |
| `Managers/GameLoop` | `GameLoop.cs` | 主循环入口，Inspector 引用其余 Manager 与 Player |
| `Managers/InputManager` | `InputManager.cs` | 绑定 `Assets/Game/Configs/GameInputActions.inputactions` |
| `Managers/UIManager` | `UIManager.cs` | 绑定各 UI Panel |
| `Managers/LevelManager` | `LevelManager.cs` | 绑定 `SpawnPoint`、`GoalTrigger` |

`GameLoop` Inspector 引用：

| 字段 | 拖入对象 |
| --- | --- |
| Input Manager | `Managers/InputManager` |
| UI Manager | `Managers/UIManager` |
| Level Manager | `Managers/LevelManager` |
| Player | `SceneRoot/GameplayLayer/Runtime_Player` |
| Player Spawn Point | `SceneRoot/GameplayLayer/SpawnPoint` |

`UIManager` Inspector 引用：

| 字段 | 拖入对象 |
| --- | --- |
| Main Menu Panel | `UI/Canvas_Menu/MainMenuPanel` |
| Gameplay Panel | `UI/Canvas_HUD` |
| Pause Panel | `UI/Canvas_Menu/PauseMenu` |
| Result Panel | `UI/Canvas_Menu/ResultPanel` |

`LevelManager` Inspector 引用：

| 字段 | 拖入对象 |
| --- | --- |
| Default Spawn Point | `SceneRoot/GameplayLayer/SpawnPoint` |
| Goal Trigger | `SceneRoot/GameplayLayer/Runtime_Exits/GoalTrigger` |
| Death Y | `-10` |

可通过菜单 **Tools → Project Structure → Setup Gameplay Game Loop** 自动完成上述挂载。

## Runtime 生成对象对应关系

```text
tilemapPrefab             -> SceneRoot/GameplayLayer/Runtime_Tilemap
playerSpawnPosition       -> SceneRoot/GameplayLayer/SpawnPoint
player                    -> SceneRoot/GameplayLayer/Runtime_Player
platforms                 -> SceneRoot/GameplayLayer/Runtime_Platforms
enemies                   -> SceneRoot/GameplayLayer/Runtime_Enemies
traps / mechanisms        -> SceneRoot/GameplayLayer/Runtime_Traps
collectibles              -> SceneRoot/GameplayLayer/Runtime_Collectibles
interactables             -> SceneRoot/GameplayLayer/Runtime_Interactables
exits / transitions       -> SceneRoot/GameplayLayer/Runtime_Exits
goalTrigger               -> SceneRoot/GameplayLayer/Runtime_Exits/GoalTrigger
visualObjects: Background -> SceneRoot/BackgroundLayer/Runtime_Background
visualObjects: Midground  -> SceneRoot/MidgroundLayer/Runtime_Midground
visualObjects: Foreground -> SceneRoot/ForegroundLayer/Runtime_Foreground
particleEffects           -> SceneRoot/EffectsLayer/Runtime_Particles
lightEffects              -> SceneRoot/EffectsLayer/Runtime_Lights
dataCollectionTriggers    -> SceneTriggers/Runtime_DataCollectionTriggers
```
