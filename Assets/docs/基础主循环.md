# 基础主循环详细实现方案

这里的“基础主循环”只实现 Demo 阶段最核心的运行闭环：

```text
MainMenu
  ↓
Loading
  ↓
Playing
  ├── Paused
  ├── PlayerDead → Respawning → Playing
  └── LevelClear → Result
```

目标是先让游戏具备：

```text
启动游戏
进入关卡
正常游玩
暂停 / 继续
玩家死亡
玩家复活
关卡完成
进入结算
重新开始
返回菜单
```

暂时不加入复杂的 AI 分析、数据上传、存档系统，只预留接口。

# 二、基础运行流程

## 1. 游戏启动流程

```text
GameLoop.Awake()
  ↓
创建 GameContext
  ↓
创建 GameStateMachine
  ↓
注册所有状态
  ↓
进入 MainMenuState
```

## 2. 每帧执行流程

```text
GameLoop.Update()
  ↓
GameStateMachine.Update()
  ↓
当前状态 Update()
```

## 3. 物理帧执行流程

```text
GameLoop.FixedUpdate()
  ↓
GameStateMachine.FixedUpdate()
  ↓
当前状态 FixedUpdate()
```

## 4. 状态切换流程

```text
当前状态 Exit()
  ↓
切换 currentState
  ↓
新状态 Enter()
```

# 四、IGameState.cs

所有游戏状态都实现这个接口。

```csharp
public interface IGameState
{
    void Enter();
    void Update(float deltaTime);
    void FixedUpdate(float fixedDeltaTime);
    void Exit();
}
```

每个状态的职责：

```text
Enter      进入状态时执行一次
Update     每帧执行
FixedUpdate 物理帧执行
Exit       离开状态时执行一次
```

# 六、GameStateMachine.cs

这是整个状态管理的核心。

```csharp
using System.Collections.Generic;
using UnityEngine;

public class GameStateMachine
{
    private readonly Dictionary<GameStateType, IGameState> states = new();

    private IGameState currentState;

    public GameStateType CurrentStateType { get; private set; }

    public void RegisterState(GameStateType type, IGameState state)
    {
        if (states.ContainsKey(type))
        {
            Debug.LogWarning($"State already registered: {type}");
            return;
        }

        states.Add(type, state);
    }

    public void ChangeState(GameStateType newStateType)
    {
        if (currentState != null && CurrentStateType == newStateType)
        {
            return;
        }

        if (!states.TryGetValue(newStateType, out IGameState newState))
        {
            Debug.LogError($"State not registered: {newStateType}");
            return;
        }

        Debug.Log($"Change State: {CurrentStateType} -> {newStateType}");

        currentState?.Exit();

        CurrentStateType = newStateType;
        currentState = newState;

        currentState.Enter();
    }

    public void Update(float deltaTime)
    {
        currentState?.Update(deltaTime);
    }

    public void FixedUpdate(float fixedDeltaTime)
    {
        currentState?.FixedUpdate(fixedDeltaTime);
    }
}
```

# 七、GameLoop.cs

`GameLoop` 是场景中的核心入口，挂在 `Managers/GameLoop` 上：

```text
Managers
├── GameLoop          (GameLoop.cs)
├── InputManager      (InputManager.cs)
├── UIManager         (UIManager.cs)
└── LevelManager      (LevelManager.cs)
```

每个 Manager 组件对应独立对象，由 `GameLoop` 在 Inspector 中引用。

完整代码：

```csharp
using UnityEngine;

public class GameLoop : MonoBehaviour
{
    [Header("Managers")]
    [SerializeField] private InputManager inputManager;
    [SerializeField] private UIManager uiManager;
    [SerializeField] private LevelManager levelManager;

    [Header("Player")]
    [SerializeField] private PlayerController player;

    [Header("Spawn")]
    [SerializeField] private Transform playerSpawnPoint;

    private GameContext context;
    private GameStateMachine stateMachine;

    private void Awake()
    {
        CreateContext();
        CreateStateMachine();
        RegisterStates();
    }

    private void Start()
    {
        stateMachine.ChangeState(GameStateType.MainMenu);
    }

    private void Update()
    {
        float deltaTime = Time.deltaTime;

        inputManager.Tick();

        stateMachine.Update(deltaTime);
    }

    private void FixedUpdate()
    {
        float fixedDeltaTime = Time.fixedDeltaTime;

        stateMachine.FixedUpdate(fixedDeltaTime);
    }

    private void CreateContext()
    {
        context = new GameContext
        {
            GameLoop = this,
            InputManager = inputManager,
            UIManager = uiManager,
            LevelManager = levelManager,
            Player = player,
            PlayerSpawnPoint = playerSpawnPoint
        };
    }

    private void CreateStateMachine()
    {
        stateMachine = new GameStateMachine();
        context.StateMachine = stateMachine;
    }

    private void RegisterStates()
    {
        stateMachine.RegisterState(GameStateType.MainMenu, new MainMenuState(context));
        stateMachine.RegisterState(GameStateType.Loading, new LoadingState(context));
        stateMachine.RegisterState(GameStateType.Playing, new PlayingState(context));
        stateMachine.RegisterState(GameStateType.Paused, new PauseState(context));
        stateMachine.RegisterState(GameStateType.PlayerDead, new PlayerDeadState(context));
        stateMachine.RegisterState(GameStateType.Respawning, new RespawnState(context));
        stateMachine.RegisterState(GameStateType.LevelClear, new LevelClearState(context));
        stateMachine.RegisterState(GameStateType.Result, new ResultState(context));
    }
}
```

# 八、InputManager.cs

基础输入管理器先不要做复杂输入系统，先封装几个核心输入。

```csharp
using UnityEngine;

public class InputManager : MonoBehaviour
{
    public float MoveX { get; private set; }
    public bool JumpPressed { get; private set; }
    public bool PausePressed { get; private set; }
    public bool ConfirmPressed { get; private set; }

    public bool GameplayInputEnabled { get; private set; }
    public bool UIInputEnabled { get; private set; }

    public void Tick()
    {
        MoveX = 0f;
        JumpPressed = false;
        PausePressed = false;
        ConfirmPressed = false;

        if (GameplayInputEnabled)
        {
            MoveX = Input.GetAxisRaw("Horizontal");
            JumpPressed = Input.GetKeyDown(KeyCode.Space);
            PausePressed = Input.GetKeyDown(KeyCode.Escape);
        }

        if (UIInputEnabled)
        {
            ConfirmPressed = Input.GetKeyDown(KeyCode.Return) || Input.GetKeyDown(KeyCode.Space);
            PausePressed = Input.GetKeyDown(KeyCode.Escape);
        }
    }

    public void EnableGameplayInput()
    {
        GameplayInputEnabled = true;
        UIInputEnabled = false;
    }

    public void EnableUIInput()
    {
        GameplayInputEnabled = false;
        UIInputEnabled = true;
    }

    public void DisableAllInput()
    {
        GameplayInputEnabled = false;
        UIInputEnabled = false;
    }
}
```

后续如果换成 Unity Input System，只需要替换 `InputManager`，不需要改状态机。

# 十、LevelManager.cs

基础关卡管理器负责：

```text
加载关卡
重置关卡
检查玩家是否死亡
检查是否通关
```

Demo 阶段可以先把关卡直接放在同一个 Scene 中，不做异步场景加载。

```csharp
using UnityEngine;

public class LevelManager : MonoBehaviour
{
    [SerializeField] private Transform defaultSpawnPoint;
    [SerializeField] private Collider2D goalTrigger;
    [SerializeField] private float deathY = -10f;

    public Transform DefaultSpawnPoint => defaultSpawnPoint;

    public void LoadLevel()
    {
        Debug.Log("Level Loaded");
    }

    public void ResetLevel()
    {
        Debug.Log("Level Reset");
    }

    public bool CheckPlayerDead(PlayerController player)
    {
        if (player == null)
            return false;

        if (player.transform.position.y < deathY)
            return true;

        if (player.IsDead)
            return true;

        return false;
    }

    public bool CheckLevelClear(PlayerController player)
    {
        if (player == null || goalTrigger == null)
            return false;

        return goalTrigger.bounds.Contains(player.transform.position);
    }
}
```

这里用 `goalTrigger.bounds.Contains()` 是最小方案。后续建议改成 `GoalTrigger` 脚本，用事件通知通关。

# 十一、PlayerController.cs

基础玩家控制器只负责：

```text
接收移动输入
执行移动
执行跳跃
死亡禁用控制
复活重置位置
```

示例代码：

```csharp
using UnityEngine;

[RequireComponent(typeof(Rigidbody2D))]
public class PlayerController : MonoBehaviour
{
    [Header("Movement")]
    [SerializeField] private float moveSpeed = 6f;
    [SerializeField] private float jumpForce = 12f;

    [Header("Ground Check")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckRadius = 0.1f;
    [SerializeField] private LayerMask groundLayer;

    private Rigidbody2D rb;

    private float moveX;
    private bool jumpRequested;

    public bool IsGrounded { get; private set; }
    public bool IsDead { get; private set; }

    private void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    public void HandleInput(InputManager input)
    {
        if (IsDead)
            return;

        moveX = input.MoveX;

        if (input.JumpPressed)
        {
            jumpRequested = true;
        }
    }

    public void FixedTick(float fixedDeltaTime)
    {
        if (IsDead)
            return;

        CheckGround();
        Move();
        Jump();
    }

    private void CheckGround()
    {
        if (groundCheck == null)
        {
            IsGrounded = false;
            return;
        }

        IsGrounded = Physics2D.OverlapCircle(
            groundCheck.position,
            groundCheckRadius,
            groundLayer
        );
    }

    private void Move()
    {
        rb.linearVelocity = new Vector2(moveX * moveSpeed, rb.linearVelocity.y);
    }

    private void Jump()
    {
        if (!jumpRequested)
            return;

        if (IsGrounded)
        {
            rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpForce);
        }

        jumpRequested = false;
    }

    public void Kill()
    {
        IsDead = true;
        rb.linearVelocity = Vector2.zero;
    }

    public void Respawn(Vector3 position)
    {
        transform.position = position;
        rb.linearVelocity = Vector2.zero;

        IsDead = false;
        moveX = 0f;
        jumpRequested = false;
    }

    public void StopMovement()
    {
        moveX = 0f;
        jumpRequested = false;

        if (rb != null)
        {
            rb.linearVelocity = Vector2.zero;
        }
    }
}
```

注意：Unity 旧版本使用 `rb.velocity`，新版本可以使用 `rb.linearVelocity`。如果你的 Unity 报错，就把所有 `linearVelocity` 改成 `velocity`。

# 十四、PlayingState.cs

这是主循环最核心的状态。

职责：

```text
启用玩家输入
更新玩家逻辑
更新死亡检测
更新通关检测
响应暂停
执行玩家物理移动
```

```csharp
public class PlayingState : IGameState
{
    private readonly GameContext context;

    public PlayingState(GameContext context)
    {
        this.context = context;
    }

    public void Enter()
    {
        UnityEngine.Time.timeScale = 1f;

        context.UIManager.ShowGameplayUI();
        context.InputManager.EnableGameplayInput();

        context.IsPlayerDead = false;
        context.IsLevelClear = false;
    }

    public void Update(float deltaTime)
    {
        if (context.InputManager.PausePressed)
        {
            context.StateMachine.ChangeState(GameStateType.Paused);
            return;
        }

        context.Player.HandleInput(context.InputManager);

        CheckPlayerDead();
        CheckLevelClear();
    }

    public void FixedUpdate(float fixedDeltaTime)
    {
        context.Player.FixedTick(fixedDeltaTime);
    }

    public void Exit()
    {
    }

    private void CheckPlayerDead()
    {
        bool dead = context.LevelManager.CheckPlayerDead(context.Player);

        if (dead)
        {
            context.Player.Kill();
            context.StateMachine.ChangeState(GameStateType.PlayerDead);
        }
    }

    private void CheckLevelClear()
    {
        bool clear = context.LevelManager.CheckLevelClear(context.Player);

        if (clear)
        {
            context.StateMachine.ChangeState(GameStateType.LevelClear);
        }
    }
}
```

# 十九、ResultState.cs

结算状态：

```text
显示结算页面
启用 UI 输入
按确认键重新开始
按 Esc 返回主菜单
```

```csharp
public class ResultState : IGameState
{
    private readonly GameContext context;

    public ResultState(GameContext context)
    {
        this.context = context;
    }

    public void Enter()
    {
        UnityEngine.Time.timeScale = 1f;

        context.UIManager.ShowResult();
        context.InputManager.EnableUIInput();
    }

    public void Update(float deltaTime)
    {
        if (context.InputManager.ConfirmPressed)
        {
            context.StateMachine.ChangeState(GameStateType.Loading);
            return;
        }

        if (context.InputManager.PausePressed)
        {
            context.StateMachine.ChangeState(GameStateType.MainMenu);
```

# 二十四、常见问题

## 1. 玩家在暂停时还能动

检查：

```text
PauseState 是否切换成功
Time.timeScale 是否设置为 0
PlayingState.FixedUpdate 是否没有继续执行
```

状态机中只有当前状态会执行，所以只要进入了 `Paused`，`PlayingState.FixedUpdate()` 就不会被调用。

---

## 2. 玩家复活后立刻又死亡

常见原因：

```text
SpawnPoint 位置太低
SpawnPoint 在死亡线 deathY 以下
玩家复活点和陷阱重叠
LevelManager.ResetLevel 没有重置机关
```

Demo 阶段先保证：

```text
SpawnPoint.y > deathY
```

---

## 3. 玩家无法跳跃

检查：

```text
GroundCheck 是否拖入
Ground Layer 是否设置正确
地面对象是否属于 Ground Layer
GroundCheck 是否在玩家脚下
GroundCheckRadius 是否太小
```

---

## 4. 通关触发不了

当前方案用的是：

```csharp
goalTrigger.bounds.Contains(player.transform.position)
```

所以要求：

```text
GoalTrigger 必须有 Collider2D
GoalTrigger 范围要足够大
玩家 Transform 中心点要进入触发区域
```

更推荐后续改成触发器事件：

```csharp
private void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Player"))
    {
        // 触发通关事件
    }
}
```
