# 项目目录结构文档

## 项目定位

本项目为 Unity 2D 平台跳跃 + 类银河恶魔城结构 + 玩家行为数据采集 + AI 分析项目。

当前采用最终场景配置方案：

```text
Unity Gameplay 场景作为运行容器
SceneConfig JSON 作为关卡配置文件
Prefab 作为对象模板
SceneBuilder 运行时生成关卡内容
DataCollectionManager 记录玩家行为
```

运行时不为每个关卡制作完整 Unity Scene。每个关卡由 `Assets/Game/Configs/Scenes/*.json` 描述，并在 `Assets/Game/Scenes/Gameplay.unity` 中动态生成。

`Assets/Game/Editor/WorkScenes` 保留为关卡可视化制作场景，用于编辑器内搭建与导出 SceneConfig，不作为运行时关卡场景。

## 目录职责

| 目录 | 职责 |
|---|---|
| `Assets/Game/Scenes` | 运行场景，只保留主菜单、加载、通用 Gameplay 容器 |
| `Assets/Game/Scripts/Core` | 主循环入口、状态机、GameContext |
| `Assets/Game/Scripts/States` | 主循环各游戏状态 |
| `Assets/Game/Scripts/Managers` | InputManager、UIManager、LevelManager |
| `Assets/Game/Scripts/SceneSystem` | SceneConfig、SceneBuilder、LayerManager、Spawner、Transition |
| `Assets/Game/Scripts/Player` | 玩家控制与玩家状态 |
| `Assets/Game/Scripts/Enemy` | 敌人行为与生成后绑定逻辑 |
| `Assets/Game/Scripts/Mechanism` | 机关、陷阱、门、开关等逻辑 |
| `Assets/Game/Scripts/Collectible` | 收集物逻辑 |
| `Assets/Game/Scripts/Camera` | 镜头跟随、边界、震屏等逻辑 |
| `Assets/Game/Scripts/DataCollection` | 行为采集、事件记录、分析数据导出 |
| `Assets/Game/Scripts/Editor` | 编辑器工具，例如场景层级生成器、配置导出器 |
| `Assets/Game/Prefabs` | 运行时可实例化对象模板 |
| `Assets/Game/Configs/Scenes` | 每个关卡一个 SceneConfig JSON |
| `Assets/Game/Configs/LevelGroups` | 章节、地图连接和关卡组配置 |
| `Assets/Game/Configs/Tables` | 敌人、平台、机关、收集物等数据表 |
| `Assets/Game/Configs/Templates` | 场景配置模板 |
| `Assets/Game/Art` | 游戏美术资源 |
| `Assets/Game/Audio` | 游戏音频资源 |
| `Assets/Game/Editor/WorkScenes` | 编辑器制作场景，不进入运行时加载流程 |

## 运行场景

运行时只使用以下 Unity Scene：

```text
Assets/Game/Scenes/MainMenu.unity
Assets/Game/Scenes/Loading.unity
Assets/Game/Scenes/Gameplay.unity
```

`Gameplay.unity` 是唯一的关卡承载容器。`SceneLoader` 接收目标 `sceneId`，`ResourceManager` 读取 `Assets/Game/Configs/Scenes` 中对应 JSON，`SceneBuilder` 在 Gameplay 场景内生成关卡对象。

## 编辑器制作场景

WorkScene 用于可视化搭建和导出配置：

```text
Assets/Game/Editor/WorkScenes/Room_001_WorkScene.unity
Assets/Game/Editor/WorkScenes/Room_002_WorkScene.unity
Assets/Game/Editor/WorkScenes/Room_003_WorkScene.unity
Assets/Game/Editor/WorkScenes/TestRoom_WorkScene.unity
```

这些场景只用于编辑器流程：

```text
WorkScene 搭建
        ↓
导出 SceneConfig JSON
        ↓
Gameplay.unity 读取 JSON
        ↓
运行时生成关卡
```

## SceneConfig 推荐结构

每个关卡对应一个 JSON：

```text
Assets/Game/Configs/Scenes/Scene_001_RuinsEntrance.json
```

配置建议包含：

```text
SceneBaseConfig
LayerConfig
TerrainConfig
PlatformConfig
ObjectConfig
EnemyConfig
MechanismConfig
CollectibleConfig
EffectConfig
AudioConfig
CameraConfig
SpawnConfig
TransitionConfig
AnalyticsConfig
```

## Prefab 路径约定

配置中的 prefab 字段以 `Assets/Game/Prefabs` 为逻辑根：

```text
Player/Player
Terrain/GroundStone
Platform/MovingStonePlatform
Enemy/Crawler
Mechanism/Spike
Collectible/Coin
Effect/DustParticle
SceneObject/BrokenPillar
UI/HUD
```

代码加载时由 `ResourceManager` 或后续 Addressables 规则统一解析。

## 推荐开发顺序

```text
1. 定义 SceneConfig JSON 数据结构
2. 实现 ResourceManager JSON 读取
3. 实现 SceneLoader
4. 实现 SceneBuilder 基础层级生成
5. 实现 LayerManager
6. 实现 TerrainBuilder
7. 实现 ObjectSpawner
8. 接入玩家出生点和镜头边界
9. 接入敌人、机关、收集物、切换点
10. 接入 EffectSpawner 和音频
11. 接入 analytics 数据采集字段
```
