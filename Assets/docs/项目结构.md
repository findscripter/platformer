# 项目目录结构

本项目为 Unity 6（6000.5.0f1）2D 平台跳跃 + 新手引导（梦泡 / 腓腓 / 塔罗）游戏。

运行时使用真实 Unity Scene，不使用 SceneConfig JSON 动态生成关卡。

## 启动与场景

```text
Boot.unity
  → 实例化 Prefabs/Managers/PersistentRoot（GameLoop + 各管理器，DontDestroyOnLoad）
  → 按入口加载 MainMenu / PlayerGuide / Gameplay
```

Build Settings 场景顺序：`Boot` → `MainMenu` → `PlayerGuide` → `Loading` → `Gameplay`。

编辑器 Play 由 `BootPlayModeRedirect` 先切到 Boot，并把原先打开的场景名写入 `BootSession.EntrySceneName`。

```text

│   │   ├── Core                  启动、状态机、GameContext、事件总线
│   │   ├── States                IGameState 实现
│   │   ├── Managers              Input / UI / Level / SceneTransition（脚本）
│   │   ├── Player / Enemy / Mechanism / Collectible / Interaction
│   │   ├── Dialogue              节点对话 + EventAction
│   │   ├── PlayerGuide           引导 MVC（当前 PlayerGuide 场景使用）
│   │   ├── UI                    HUD / 对话 UI / 菜单；UI/PlayerGuide 含塔罗与旧 Flow
│   │   ├── Background / Camera / Rendering / Save
│   │   └── Editor                一键搭建工具（Tools/GameJam）
│   ├── Prefabs
│   │   ├── Managers/PersistentRoot.prefab
│   │   ├── Enemy / Mechanism / Collectible / Platform / PlayerGuide
│   │   └── Player / Effect / UI / Terrain / SceneObject（占位，供后续预制体）
│   ├── Resources                 运行时 Resources.Load
│   │   ├── Player                PlayerAnimator + idle/run/jump/attack/landing clips
│   │   ├── Enemy                 PatrolEnemy.controller
│   │   └── PlayerGuide/TarotCards
│   ├── Animations                怪物 / 腓腓 clip（玩家运行时 clip 在 Resources/Player）
│   ├── Art                       角色、场景、UI、塔罗、特效
│   ├── Audio                     BGM / SFX（目录已建，资源待接入）
│   ├── Configs                   Input Actions、引导文本与气泡布局
│   ├── Shaders
│   └── Editor/WorkScenes         编辑器关卡草稿，不进 Build

```

仓库其它位置：

```text
design/                 需求、分镜、塔罗/对话设计
docs/engine-reference/  Unity 版本备忘
production/              本地工作区（screenshots / 会话草稿，不入库）
美术资源/               原始解压包，不进 Unity
```

## 运行时职责（实际代码）

| 系统 | 入口 | 说明 |
|---|---|---|
| 主循环 | `GameLoop` + `GameStateMachine` | 状态：MainMenu / PlayerGuide / Loading / Playing / Paused / PlayerDead / Respawning / LevelClear / Result / Dialogue |
| 依赖 | `GameContext` | 持有管理器、玩家、关卡标志 |
| 事件 | `EventCenter` + `GameEvents` | 类型化总线 |
| 对话 | `DialogueManager` + `DialogueSO` 节点 | Text / Choice / Input / Event / End |
| 交互 | `InteractionManager` + `IInteractable` | NPC、门、开关、切场景 |
| 存档 | `SaveSystem` | `persistentDataPath/game_save.json` |
| 引导 | `PlayerGuideController`（MVC） | Frame 1–10；塔罗由 `TarotDrawController` |
| 玩家 | `PlayerController` + `PlayerAnimationStateController` | Resources 中的 PlayerAnimator |

## 不要再使用的路径

| 已移除 | 原因 |
|---|---|
| `Assets/Scripts/` | 早期 DreamGame 命名空间原型，与正式对话/引导类重名 |
| `Assets/Art/` | 旧导入目标，现统一 `Assets/Game/Art` |
| `Assets/Data/`、`Assets/Scenes` | 空壳 |
| `Assets/Screenshots/` | 截图不当纹理；已迁到 `production/screenshots/` |
| `Assets/Game/Scripts/Managers/PersistentRoot.prefab` | 已迁到 `Prefabs/Managers/` |
| `Assets/Game/player_guide/` | 已并入 `Configs/PlayerGuide/` |

`Assets/Game/Scripts/UI/PlayerGuide/PlayerGuideFlowController` 与 `…V2` 是引导 MVC 之前的实现，场景已改挂 `PlayerGuideController`。不要再往场景上挂旧 Flow；塔罗仍用同目录的 `TarotDrawController`。
