# Frame 6 对话细化（6-1 至 6-8）

## 6-1 | 接住梦核
**建议时长**: 1.4-1.6s

**动作**:
- 腓腓看着梦核，轻轻接住。
- 梦核：微弱蓝紫光。

**对话**:
「……你也听见了吗？」

---

## 6-2 | 低头看梦核
**建议时长**: 1.7-1.9s

**动作**:
- 腓腓低头，视线落在梦核上。
- 梦核：保持微光。

**对话**:
「已经很久，没有人停下来听它们说话了。」

---

## 6-3 | 指尖轻抚
**建议时长**: 1.8-2.0s

**动作**:
- 指尖轻轻抚过梦核。
- 梦核：一圈蓝紫涟漪。

**对话**:
「它刚刚……还在很多话没说完。」

---

## 6-4 | 抬头看玩家
**建议时长**: 1.7-1.9s

**动作**:
- 腓腓抬头看向玩家。
- 梦核：微光稳定。

**对话**:
「每一个梦，好像都想告诉我主人一些事情。」

---

## 6-5 | 安静停顿
**建议时长**: 1.9-2.1s

**动作**:
- 腓腓捧着梦核，尾巴轻轻晃了下。
- 梦核：光晕微变弱。

**对话**:
「只是很多人嫌来以后，就忘记回头听了。」

---

## 6-6 | 短句留白
**建议时长**: 1.2-1.4s

**动作**:
- 腓腓稍向玩家，停半拍。
- 梦核：轻轻亮一下。

**对话**:
「如果你还记得。」

---

## 6-7 | 引导进入
**建议时长**: 2.0-2.2s

**动作**:
- 腓腓把梦核微微向前递出。
- 梦核：光晕增强。

**对话**:
「我们一起去看看，它到底想告诉你什么。」

---

## 6-8 | 转场
**建议时长**: 0.8-1.0s

**动作**:
- 梦核光晕扩开，画面渐隐。
- 梦核：蓝紫光扩散后进入 Fade。

**显示文字**:
Fade

**对话**:
无对白

---

## 技术实现要点

### 对话系统配置
```csharp
// DialogueData ScriptableObject
public class Frame6Dialogue : DialogueData
{
    public List<DialogueNode> nodes = new()
    {
        new TextNode { 
            text = "……你也听见了吗？",
            duration = 1.5f,
            speakerName = "腓腓"
        },
        new TextNode { 
            text = "已经很久，没有人停下来听它们说话了。",
            duration = 1.8f
        },
        // ... 其余 6 个节点
    };
}
```

### 动画触发
- 每段对话对应一个 Feifei Animator 状态
- 梦核的光效用 Shader Graph + Timeline 控制
- 6-8 的 Fade 触发 `SceneTransitionManager.FadeOut()`

### 交互模式
- 玩家点击任意位置 → 下一段对话
- 或自动播放模式（根据 duration 自动切换）
- 最后一段（6-8）自动进入 Frame 7

### UI 布局
- 对话框位置：屏幕底部居中，上方留出角色显示区
- 文字动画：逐字显示（0.05s/字）或整句淡入
- 跳过按钮：右上角（可选，看是否允许跳过）
